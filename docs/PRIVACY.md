# Privacy and data flow

VO Studio runs on your computer. Speech synthesis and forced alignment run on
ElevenLabs, so generation requires an internet connection.

## What goes where

| Data | Browser | Local server / files | ElevenLabs |
| --- | --- | --- | --- |
| API key | Input field and request memory; excluded from preferences | Used in request memory; excluded from job metadata | Sent over HTTPS in the `xi-api-key` header |
| Draft script | Text field; excluded from preferences | Not saved until generation starts | Sent when generating speech or aligning audio |
| Submitted script | Remains in the editor | Saved as `outputs/<job-id>/transcript.txt` | Sent for speech synthesis and alignment |
| Generated audio | Played through the local server | Saved as a WAV in `outputs/<job-id>/` | Generated by ElevenLabs, then uploaded for alignment |
| Alignment | Available as a download | Saved as the provider's JSON response | Computed by ElevenLabs |
| Project and voice settings | Saved in `localStorage` | Saved in job metadata | Voice, model and synthesis settings sent as needed |

The browser remembers project name, episode ID, voice name and ID, model, sample
rate and voice settings. These preferences belong to the local URL's origin; a
different port has separate storage. The app does not put the API key or script
in `localStorage`.

## Local safeguards

- The server binds to `127.0.0.1` and validates the request Host header and POST
  Origin header.
- API keys are excluded from the job data returned to the browser and written
  to metadata. Error handling redacts the submitted key and known local paths
  before returning or saving error messages.
- Request bodies are not logged by the app. The interface uses local assets,
  with no analytics scripts or remote font requests.
- `outputs/`, environment files, logs, Finder aliases and OS metadata are ignored
  by Git. The public preview contains no account or project data.

Output files are ordinary, unencrypted files on your computer. They contain your
script, voice details, project names and audio, and should be treated accordingly.
The server is designed for a single local user; it has no login system and should
not be exposed as a public service. Origin checks are not authentication against
other programs running on your computer.

## Remove local data

Stop the app and delete the relevant job directory under `outputs/` to remove its
audio, transcript, alignment and history. Clear the site's storage in your browser
to remove saved preferences. Close the tab to discard the in-memory key and draft
script. Browser extensions and password managers operate independently of the app.

Deleting local files does not delete data held by ElevenLabs. Provider retention
and processing are governed by your account and ElevenLabs policies; this app does
not request a special zero-retention mode.
